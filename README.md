## 🌟 Overview

This repository houses the source code for the personal developer portfolio of **Istiak Ahmad**, a Computer Science & Engineering graduate from Daffodil International University. Designed from the ground up to showcase web engineering prowess, algorithm visualizers, and data-driven systems, the site pairs an obsidian cyber-glass aesthetic with fluid animations and responsive mobile architecture.

---

## 🚀 Key Features

- 🌌 **Interactive Particle Physics Canvas**: Real-time constellation particle network with dynamic mouse repulsion and particle connection algorithms.
- 🎯 **3D Perspective Card Tilt**: Smooth, hardware-accelerated 3D hover tilt responding dynamically to cursor position across project and milestone cards.
- 💡 **Fluid Cursor Glow Tracer**: Ambient luminous light orb trailing mouse movement via linear interpolation (lerp).
- ⌨️ **Dynamic Typewriter Subtitle**: Animated role cycle highlighting key disciplines (Software Engineer, Full-Stack Developer, CSE Graduate, Competitive Thinker).
- 🔊 **Web Audio API Sound Synthesizer**: Pure JavaScript audio synthesizer providing clean acoustic feedback for clicks and modal interactions (with sound mute/unmute control).
- 🗺️ **Milestones & Journey Timeline**: Interactive timeline chronicling academic milestones, leadership positions (Technical Lead at DIU Computer & Programming Club), and volunteer work.
- 🏆 **Honors & National Awards**: Showcase of competitive achievements, including National Inter-Cantonment Champion, Senior Science Festival honors, and Francophonie laureate recognition.
- 👁️ **Live Project Demo Modal**: Modal previews for featured repositories with direct access to codebases and tech tags.
- 📥 **Integrated CV / Resume Download**: Seamless one-click download for up-to-date resume in PDF format.
- 📱 **Mobile-First Responsive Layout**: Smooth drawer navigation and adaptive CSS grids optimized for mobile, tablet, laptop, and ultra-wide displays.

## 💻 Local Setup & Development

To run this portfolio locally without any external dependencies or build steps:

### 1. Clone the repository
```bash
git clone https://github.com/istiak777/Personal-portfolio-.git
cd Personal-portfolio-
```

### 2. Launch in your browser
You can open `index.html` directly in any web browser:
```bash
# Windows PowerShell
Start-Process index.html

# Or start a quick Python local server
python -m http.server 5500
```
Then navigate to `http://localhost:5500` in your favorite browser.

### 3. Debugging via VS Code
Open the project folder in VS Code, go to the **Run & Debug** tab, and select:
- **Launch index.html (Direct File)**, or
- **Launch Microsoft Edge**

## 🌐 Deploying to GitHub Pages

To make your portfolio accessible to anyone worldwide:

1. Push your repository commits to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete flagship portfolio"
   git push origin main
   ```
2. Navigate to your repository on GitHub: `https://github.com/istiak777/Personal-portfolio-`
3. Click on **Settings** > **Pages** in the left sidebar.
4. Set the **Source** branch to `main` and folder to `/ (root)`.
5. Click **Save**. Within minutes, your site will be live at:
   `https://istiak777.github.io/Personal-portfolio-/`
